# 國立臺北商業大學 資訊管理系 選課系統

## 專案簡介

本專案是一個針對學生設計的線上選課、加課、退選與個人課表管理系統，模擬實際校務系統的選課流程。系統提供課程瀏覽、即時加退選、時段衝突檢查、名額限制等功能，協助學生有效管理自己的課表。

## 專案目的

- 提供學生便捷的線上選課介面，取代傳統紙本或人工選課方式
- 即時檢查課程時段衝突，避免同一時段重複選課
- 控制課程名額上限，確保選課公平性
- 限制選課時段，僅於開放的選課期間才能加退選
- 提供個人課表視圖，讓學生清楚掌握已選課程與上課時程
- 依年級篩選課程，符合系上選課規則

## 系統功能

### 學生功能
- **課程列表瀏覽**：查看所有可選課程，支援依課程代碼、課程名稱、授課教師搜尋
- **年級篩選**：可依據年級（大一～大四）篩選適用課程
- **加選課程**：於選課期間內加入課程，系統自動檢查時段衝突與名額
- **退選課程**：於選課期間內退選已選課程
- **個人課表**：以清單形式查看已選課程、上課時間、地點與學分統計
- **時段衝突檢查**：自動偵測新選課程是否與已選課程時間重疊
- **名額限制**：課程額滿時無法加選
- **選課期間限制**：僅於管理員設定的選課期間內開放加退選

### 管理員功能（Django 後台）
- **課程管理**：新增、編輯、刪除課程資料（課程代碼、名稱、學分、類型、適用年級、授課教師、名額等）
- **上課時段管理**：設定課程的星期、上課時間、下課時間及教室
- **選課名單管理**：檢視各課程的選課學生名單
- **選課期間設定**：設定選課開始與結束時間，並啟用/停用選課功能
- **使用者與角色管理**：管理學生、教師帳號及權限

## 技術架構

- **框架**：Django 6.1.2
- **程式語言**：Python 3.14.7
- **資料庫**：SQLite（預設）
- **前端**：Django Templates + Bootstrap 5.3.3 + Bootstrap Icons
- **套件管理**：uv

## 角色設計

| 角色 | 權限說明 |
|---|---|
| 學生（Student） | 瀏覽課程、加選、退選、查看個人課表 |
| 教師（Teacher） | 可透過 Profile 設定（預留擴充空間） |
| 管理員（Admin） | 完整系統管理權限，可透過 Django 後台操作所有資料 |

## 資料模型

| 模型 | 說明 |
|---|---|
| `Profile` | 使用者擴充資料，記錄角色（學生/教師/管理員）及學號 |
| `Course` | 課程基本資料（課程代碼、名稱、學分、類型、適用年級、授課教師、名額） |
| `CourseTimeSlot` | 課程上課時段（星期、開始時間、結束時間、教室） |
| `Enrollment` | 選課紀錄（學生與課程的對應關係） |
| `EnrollmentPeriod` | 選課期間設定（開始時間、結束時間、是否啟用） |

## 安裝與執行

### 環境需求
- Python 3.14.7 或以上
- uv（已包含於專案環境）

### 步驟

1. **進入專案目錄**
```bash
cd "D:\Django demo_1027"
```

2. **啟動虛擬環境與伺服器**
```bash
.\.venv\Scripts\python manage.py runserver
```

3. **開啟瀏覽器**
瀏覽 [http://127.0.0.1:8000](http://127.0.0.1:8000)

### 首次使用設定

1. **建立管理員帳號**
```bash
.\.venv\Scripts\python manage.py createsuperuser
```

2. **登入管理後台**：[http://127.0.0.1:8000/admin](http://127.0.0.1:8000/admin)

3. **新增課程資料**
   - 進入 `課程 > 課程` 新增課程，並設定適用年級
   - 進入 `課程 > 課程時段` 為課程新增上課時間與地點
   - 進入 `課程 > 選課期間` 設定選課時段並勾選「啟用」

4. **建立學生帳號**
   - 進入 `驗證與授權 > 使用者` 新增學生帳號
   - 進入 `帳號 > 個人檔案` 為該使用者新增 Profile，角色設定為「學生」

## 使用說明

- **課程列表**：首頁顯示所有課程，可使用上方的年級下拉選單或搜尋欄篩選
- **加選**：在課程列表點擊「加選」按鈕，系統會自動檢查時段衝突、名額是否已滿
- **退選**：可在課程列表或「我的課表」頁面點擊「退選」
- **個人課表**：查看個人已選課程清單，包含完整的上課時間、地點與學分總計

## 注意事項

- 本系統目前使用 SQLite 資料庫，適用於開發與測試環境
- `settings.py` 中的 `SECRET_KEY` 僅供開發測試使用，實際部署時需更換
- 選課功能僅在 `選課期間` 啟用且於時間範圍內才可使用
- 時段衝突檢查以星期及時間區間判斷，避免同一天同時段選修兩門課
